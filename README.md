## 📝 Deskripsi Projek

**OWSHINT** adalah sebuah *Open Source Intelligence (OSINT)* berbasis CLI (Command Line Interface) yang dirancang untuk membantu proses pengumpulan informasi (*information gathering*) secara cepat, efisien, dan interaktif. Ditulis menggunakan bahasa pemrograman Python dan memanfaatkan *library* `rich` untuk menghasilkan visualisasi terminal yang modern dan estetik.

> **Developer:** Cerberuz69

## ✨ Fitur Utama

| Fitur | Deskripsi | Status |
| :--- | :--- | :---: |
| 🔍 **Lacak Username** | Memeriksa ketersediaan target *username* di berbagai platform media sosial besar secara simultan. | ✔️ Active |
| 🌐 **Scanning Web Subdomain** | Memetakan subdomain aktif dari domain target untuk memetakan *attack surface*. | ✔️ Active |
| 🖼️ **Ekstrak Metadata Gambar** | Menarik informasi tersembunyi (EXIF Data) dari file gambar untuk analisis forensik digital. | ✔️ Active |
